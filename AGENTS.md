# OneBox UI preferences

Apply these preferences to future page and component changes:

- Keep the interface minimal and consistent with existing OneBox pages. Remove redundant titles, helper copy, labels, and decorative wrappers when their purpose is already clear.
- Keep spacing and typography compact and balanced. Avoid oversized headings, tall empty areas, and a visually top-heavy layout.
- Avoid unnecessary borders, card frames, button fills, and accent colors. Use the existing light/dark theme tokens so both themes work; keep controls neutral unless color carries useful meaning.
- For close controls, reuse the existing `LUCIDE_X_MARKUP` icon in a bare icon button without a boxed button treatment.
- On mobile, fit the page to one viewport when practical; let long editors, lists, or results scroll inside their own region.
- Use input placeholders for examples instead of separate example buttons. Clearing an input should reveal its placeholder example.

Treat screenshot markup as the intended visual target and tune the actual spacing, hierarchy, and control treatment to match it.
